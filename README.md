학생용 올인원 허브. 링크 하나로 그날 수업·슬라이드·과제·프롬프트·도구·규칙을 모두 확인합니다.
`index.html` 단일 파일 · 외부 요청 0개 · 모노스페이스 장부(ledger) 스타일.

## 매일 아침 1분 운영

`index.html` 안의 `<script>` 맨 위 `CONFIG` 블록만 수정하고 다시 배포합니다.

- **슬라이드**: 그날 회차의 `slides:""` 에 구글 슬라이드 공유 링크를 붙여넣기
  (구글 슬라이드 → 공유 → "링크가 있는 모든 사용자 · 뷰어"). 비우면 자동으로 `[공개 예정]`.
- **자료실**: `RESOURCES` 의 각 URL을 채우면 활성화. 비우면 `[공개 예정]`.
- 날짜·제목·과제·도구는 이미 채워져 있어 건드리지 않아도 됩니다.

## 배포

- **GitHub Pages**: 이 저장소 Settings → Pages에서 자동 배포 (main 브랜치 / root).
- **Netlify**: 폴더를 통째로 https://app.netlify.com/drop 에 드래그.
- **Vercel**: `vercel --prod` (또는 대시보드에서 이 GitHub 저장소 Import).

수정할 때마다 같은 방법으로 다시 올리면 갱신됩니다.
