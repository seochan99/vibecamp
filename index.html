Cursor 단축키
Cmd/Ctrl + L AI 채팅 · Cmd/Ctrl + K 코드 인라인 편집 · Cmd/Ctrl + I 컴포저(여러 파일 한 번에) · Tab AI 자동완성 수락. 에러가 나면 메시지를 그대로 채팅에 붙여넣고 “고쳐줘”.
Netlify 배포 3단계 · TRACK 1·2
① 내 프로젝트 폴더를 통째로 app.netlify.com/drop 에 드래그 → ② 생성된 URL 확인 → ③ Site settings → Change site name 으로 주소 변경. 고치면 같은 폴더를 다시 드래그하면 갱신됩니다.
Vercel 배포 · TRACK 3
GitHub 저장소를 vercel.com/new 에서 Import → 이후 git push 할 때마다 자동 배포됩니다. (이 수업 사이트도 같은 방식으로 배포돼 있어요.)
